# BrainStorm X：マネタイズ＆コスト試算レポート（Gemini 2.5 Flash想定）

## 1. APIコスト試算
Gemini 2.5 Flashの低価格帯を活かした、1回のアクション（「ツイート」に対する30名のリプライ生成）あたりのコスト計算。

### 試算条件
- **入力トークン**: 約1,500 tokens（ユーザーの投稿 + 30名分のペルソナ属性 + システムプロンプト）
- **出力トークン**: 約4,500 tokens（150 tokens × 30名分のリプライ）
- **単価（Gemini 2.5 Flash目安）**:
  - 入力: $0.075 / 1M tokens
  - 出力: $0.30 / 1M tokens

### 1「ブラスト」（30リプライ）あたりの原価
- 入力コスト: $0.0001125
- 出力コスト: $0.00135
- **合計コスト: $0.0014625（約 0.22円 ※$1=150円計算）**

**結論:**
100円の原価で約450回ものフルシミュレーションが可能。この圧倒的な粗利の高さが、強力なフリーミアムモデルを支えます。

## 2. 収益モデル案（B2C特化）

### A. フリーミアム・モデル（基本）
- **無料枠**:
  - 1日3回までの「ブラスト」
  - スレッド保存数：最大3つ
- **プレミアム（月額 980円）**:
  - ブラスト回数無制限
  - 特定の「専門家集団（投資家、技術者、主婦等）」を指名して召喚する機能
  - 企画書エクスポート機能

### B. 従量課金 / ブースト（追加収益）
- **深掘りブースト（120円/10チケット）**:
  - 深掘りアクションを10回追加。
  - 動画広告視聴でも1回分付与。

## 3. 損益分岐点（Break-even Point）
月額 980円のユーザーが毎日5回ブラスト（月150回）利用した場合：

- **月間原価**: 0.22円 × 150 = 33円
- **利益率**: 約96%（サーバー代・決済手数料を除く）

非常に高い利益率を確保できるため、広告費に予算を回してユーザー数を追う戦略が有効です。
