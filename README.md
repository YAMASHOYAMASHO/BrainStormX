# BrainStormX

A Flutter application for brainstorming and idea management.

## Getting Started

This project is a Flutter application. To get started with Flutter development:

### Prerequisites

- Flutter SDK (>= 3.0.0)
- Dart SDK (included with Flutter)
- An IDE with Flutter support (VS Code, Android Studio, IntelliJ IDEA)

### Installation

1. Install Flutter SDK from [flutter.dev](https://flutter.dev/docs/get-started/install)
2. Clone this repository
3. Run `flutter pub get` to install dependencies

### Running the app

To run the app in debug mode:

```bash
flutter run
```

### Testing

To run tests:

```bash
flutter test
```

### Building

To build for production:

```bash
# For Android
flutter build apk

# For iOS
flutter build ios

# For Web
flutter build web
```

## Project Structure

```
lib/          - Main application code

android/      - Android-specific code

```
